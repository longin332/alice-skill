# alice-skill
# Навык для Алисы с нейросетью

Навык отвечает на вопросы голосом, помнит разговор, ищет свежую
информацию в интернете. Всё на бесплатных тарифах.

## Что понадобится 

1. Аккаунт **GitHub** — github.com
2. Аккаунт **Render** — render.com (вход через GitHub)
3. Ключ **Groq** — console.groq.com → API Keys → Create API Key (начинается с `gsk_`)
4. База **Upstash Redis** — upstash.com → Create Database → Redis, регион
   **Frankfurt (eu-central-1)**, тариф Free. Скопируй `UPSTASH_REDIS_REST_URL`
   и `UPSTASH_REDIS_REST_TOKEN` (НЕ Read-Only токен)
5. Ключ **Tavily** — tavily.com → Dashboard → API Key (начинается с `tvly-`)
6. Аккаунт **cron-job.org** — чтобы сервер не засыпал
7. Яндекс-аккаунт для **dialogs.yandex.ru**

Некоторые сайты из России открываются только через VPN.
На работу навыка это не влияет.

## Установка

### 1. Копия кода
Нажми зелёную кнопку **Use this template → Create a new repository**.
Название любое, тип Private.

### 2. Сервер на Render
1. render.com → **New → Blueprint**
2. Выбери свой новый репозиторий
3. Render покажет поля для ключей — вставь ключи из списка выше.
   `GEMINI_API_KEY` можно оставить пустым
4. Нажми **Apply** / **Deploy** и подожди 3–5 минут
5. Скопируй адрес сервиса вида `https://....onrender.com`

### 3. Проверка
Открой в браузере адрес сервиса — должно быть `{"status":"ok"}`.

Пароль для проверки: на Render → твой сервис → **Environment** →
значение `DEBUG_TOKEN`. Открой:

`https://ТВОЙ-АДРЕС.onrender.com/debug?token=ПАРОЛЬ`

Должно быть `"ok": true` и ответ про планеты.

### 4. Чтобы сервер не засыпал
cron-job.org → **Create cronjob** → URL: адрес сервиса → каждые 10 минут.

### 5. Навык в Яндекс Диалогах
1. dialogs.yandex.ru/developer → **Создать диалог → Навык**
2. Имя — своё, уникальное, 2–5 слов, без слов «Алиса», «Яндекс»
3. Backend → **Webhook URL** → адрес сервиса (с `https://` и `/` в конце)
4. Тип доступа → **Приватный**
5. Сохрани, проверь во вкладке **Тестирование**, затем **Опубликовать**

## Настройки (по желанию)

Меняются на Render → Environment, код трогать не нужно.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `GROQ_MODEL` | `openai/gpt-oss-20b` | модель Groq |
| `PROVIDER_ORDER` | `groq,gemini,openrouter` | порядок моделей |
| `TOTAL_BUDGET` | `3.8` | секунд на ответ (лимит Алисы 4,5) |
| `HISTORY_MAX_MESSAGES` | `6` | сколько реплик помнить |
| `HISTORY_TTL` | `3600` | через сколько секунд забыть разговор |
| `CACHE_ENABLED` | `1` | `0` — выключить кэш |
| `SEARCH_ENABLED` | `1` | `0` — выключить поиск |
| `SEARCH_TRIGGER_WORDS` | `сегодня,сейчас,...` | слова, при которых включается поиск |

## Если что-то не работает

Открой `/debug?token=ПАРОЛЬ` — в поле `log` написано, что сломалось.
Частые причины:
- `HTTP 401` — неверный ключ
- `HTTP 404 ... model` — модель недоступна, смени `GROQ_MODEL`
- `"memory_enabled": false` — не заданы переменные Upstash
